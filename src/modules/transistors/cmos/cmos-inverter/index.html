0. Historical Origin: Frank Wanlass & Chih-Tang Sah (1963)

Step 0 · Origins · Fairchild Semiconductor

Early PMOS and NMOS logic families burned steady-state DC standby power whenever an output sat low, because a permanently active pull-up load drew current straight from supply to ground. In 1963 at Fairchild Semiconductor, Frank Wanlass and Chih-Tang Sah unveiled the complementary MOS (CMOS) inverter topology pairing an enhancement PMOS pull-up with an enhancement NMOS pull-down.

Zero Static Standby Power Breakthrough

By tying the shared input gate to both complementary transistors, either the PMOS or the NMOS is strictly cut off in steady state (IN = 0 or IN = 1), slashing static dissipation by six orders of magnitude compared to resistor-loaded logic and unlocking battery-powered watches, spacecraft electronics, and VLSI microprocessors.

Why Twin Wells Matter

Integrating both channel polarities cleanly on a single silicon wafer required isolated complementary wells (N-Well for PMOS, P-Well/P-Substrate for NMOS) biased via body taps to keep junctions reverse-biased and prevent latch-up.

1. Circuit Architecture, Complementary Switching & Floating State

PUN to VDD, PDN to GND, Zero Static Power

The CMOS Inverter is the primary building block of digital integrated circuits. It consists of two complementary enhancement MOSFETs whose gates are connected to common input VIN and drains to common output VOUT:

Pull-Up Network (PUN)

PMOS transistor connected between VDD (+1.0V) and OUT. Conducts when VIN = 0V (active-low gate) to pull OUT to VDD.

Pull-Down Network (PDN)

NMOS transistor connected between OUT and GND (0V). Conducts when VIN = VDD (active-high gate) to discharge OUT to GND.

Zero Static DC Power

In either steady logic state (0 or 1), one transistor is completely OFF while the other is ON. No direct DC path exists between VDD and GND, resulting in near-zero static power dissipation.

IN = 0V ⟹ PMOS ON, NMOS OFF ⟹ VOUT = VOH = VDD  |  IN = VDD ⟹ PMOS OFF, NMOS ON ⟹ VOUT = VOL = 0V
Floating High-Z State (IN = OFF): When the input is disconnected or floating, both PMOS and NMOS enter weak inversion subthreshold leakage, yielding undefined intermediate output voltages.

2. Voltage Transfer Characteristic (VTC) & 5 Operating Regions

5 Distinct Analytical Regimes (A through E)

As input voltage VIN increases from 0V to VDD, the inverter traverses 5 distinct operating regions based on the conduction state of NMOS and PMOS:

Region Input Range (VIN) NMOS State PMOS State Output Voltage (VOUT) & Analytical Behavior
Region A 0 ≤ VIN < VTH,n Cutoff (IDn = 0) Linear (VSD ≈ 0) VOUT = VOH = VDD. PMOS ties OUT to VDD with zero current.
Region B VTH,n ≤ VIN < VM Saturation (VDS > VGS - VTH,n) Linear (VSD < VSG - |VTH,p|) VOUT begins dropping sharply from VDD as NMOS begins conducting. High voltage gain.
Region C VIN ≈ VM = 0.5 VDD Saturation Saturation Both transistors in saturation. Steepest slope with peak gain |Av| > 10. Direct shoot-through current Ipeak flows.
Region D VM < VIN ≤ VDD - |VTH,p| Linear (VDS < VGS - VTH,n) Saturation (VSD > VSG - |VTH,p|) VOUT approaches GND as PMOS pinches off into saturation.
Region E VDD - |VTH,p| < VIN ≤ VDD Linear (VDS ≈ 0) Cutoff (IDp = 0) VOUT = VOL = GND (0V). NMOS ties OUT to GND with zero steady-state current.

3. Inverter Switching Threshold (VM)

Equating Saturation Currents: I_Dn = I_Dp at V_IN = V_OUT

The switching threshold VM is defined as the unique operating point where input equals output: VIN = VOUT = VM. Equating NMOS and PMOS saturation currents yields:

VM = [ VTH,n + r · (VDD - |VTH,p|) ] / (1 + r)   where   r = √(kp / kn)
Symmetric Inverter Condition (r = 1): When kn = kp and VTH,n = |VTH,p|, the switching threshold lies exactly at the mid-rail: VM = VDD / 2 = 0.50V.

4. Noise Margins (NMH & NML)

Unity-Gain Points (dVOUT / dVIN = -1)

Noise margins characterize the noise immunity of the digital logic gate:

Noise Margin Low (NML)

Maximum noise voltage added to a Logic 0 that will not cause a false Logic 1 transition:

NML = VIL - VOL = VIL - 0V = VIL
Noise Margin High (NMH)

Maximum noise voltage subtracted from a Logic 1 that will not cause a false Logic 0 transition:

NMH = VOH - VIH = VDD - VIH

In symmetric CMOS inverters, robust noise margins are achieved: NML ≈ NMH ≈ 0.4 × VDD.

5. Dynamic Power Dissipation & Propagation Delay

Pdyn = CL · VDD² · f, tp = ½ (tpHL + tpLH)

Total CMOS power dissipation consists of dynamic switching energy, short-circuit current, and static subthreshold leakage:

Ptotal = Pdyn + Psc + Pleak = CL · VDD² · fclk + Ipeak · VDD · fclk · Δtsc + Ileak · VDD
Propagation Delay: tpHL ≈ (CL · VDD) / [kn(VDD - VTH,n)²]  ·  tpLH ≈ (CL · VDD) / [kp(VDD - |VTH,p|)²]

6. Euler Path Layout & Lambda Design Rules

Diffusion Sharing, Contact Spacing, SDE Overlap

In physical VLSI layout, PMOS and NMOS active areas are aligned in parallel strips under a continuous vertical polysilicon gate wire. Placing N-well and P-substrate taps at regular pitch satisfies Mead-Conway lambda design rules and completely suppresses parasitic latchup.
