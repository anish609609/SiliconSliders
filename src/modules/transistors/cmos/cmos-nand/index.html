CMOS 2-Input NAND Gate Physics & Dynamic Delay

Parallel PUN (2× PMOS) + Series PDN (2× NMOS) · OUT = !(A · B)

1. Dual Network Topology & Boolean Operation

OUT = !(A · B), Parallel PMOS + Series NMOS

The CMOS 2-Input NAND Gate is a universal digital logic gate implementing the Boolean function Y = !(A · B). It is engineered with dual complementary networks:

Pull-Up Network (PUN): 2× PMOS in Parallel

Transistors MP1 (Gate A) and MP2 (Gate B) are connected in parallel between VDD (+1.0V) and OUT. If either input A=0 OR B=0, at least one PMOS turns ON to strongly pull the output HIGH to VDD.

Pull-Down Network (PDN): 2× NMOS in Series

Transistors MN2 (Gate B, top) and MN1 (Gate A, bottom) are connected in series between OUT and GND. Current can discharge to ground if and only if both A=1 AND B=1 simultaneously.

3. Transistor Sizing Rules & Series Stacking Penalty

(Wn/L)NAND = 2 × (Wn/L)INV

When two identical NMOS transistors are stacked in series, their on-resistances sum together: RPDN = Rn1 + Rn2 = 2 Rn. To match the pull-down delay of a reference unit inverter (Rinv,N):

(Wn / L)NAND = 2 × (Wn / L)INV
Doubling NMOS channel width halves each transistor's on-resistance (Rn = Rinv / 2), keeping total stack resistance equal to Rinv.

Parallel PMOS Sizing: In the worst-case pull-up transition (A=0, B=1 or A=1, B=0), only a single PMOS conducts. Therefore, each PMOS width must match the unit inverter PMOS width:

(Wp / L)NAND = 1 × (Wp / L)INV ≈ 2 × (Wn / L)INV
Worst-case pull-up resistance equals Rinv,P without needing to oversize PMOS.

4. Internal Node Capacitance, Charge Sharing & Body Effect

Cint = Cdb1 + Csb2, VTH2 = VTH0 + γ(√(2φF + Vint) - √(2φF))

The intermediate N+ diffusion junction between MN1 and MN2 introduces a parasitic internal node capacitance Cint = Cdb,MN1 + Csb,MN2:

Body Effect on Top NMOS (MN2)

While MN1 has its source tied directly to GND (VSB1 = 0), MN2's source sits at internal potential Vint > 0. This creates body reverse bias VSB2 = Vint, increasing MN2's threshold voltage via the body effect and reducing overdrive.

Charge Sharing Glitches

If B transitions HIGH while A remains LOW, charge on CL is shared with internal capacitor Cint, causing an undesirable momentary voltage dip (glitch) on the output line.

5. Propagation Delay Asymmetry (tpLH vs. tpHL)

tpLH (2 PMOS parallel) = ½ tpLH (1 PMOS)
Low-to-High: tpLH(both) ≈ 0.69 · (Rp / 2) · CL  |  tpLH(single) ≈ 0.69 · Rp · CL
High-to-Low: tpHL ≈ 0.69 · [Rn1 · (CL + Cint) + Rn2 · CL]

Input pattern dependent delay: If input B is already 1 and A rises, Cint was already discharged, making this transition noticeably faster than if input A was 1 and B rises.

6. Logical Effort & Euler Graph Topology

Logical Effort g = 4/3, Continuous Active Diffusion

Logical Effort: Input capacitance per pin is Cin = 2 (NMOS) + 2 (PMOS) = 4 units. Relative to an inverter (3 units), the NAND gate has a logical effort of g = 4/3 ≈ 1.33.

Euler Path Layout: The shared diffusion strip in this 3D model follows an Euler path ordering (A - B), merging the drain of MN1 and source of MN2 into a single compact diffusion node to minimize parasitic area and capacitance.
